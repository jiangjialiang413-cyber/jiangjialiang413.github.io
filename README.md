# 率土同盟战报台账

直接双击 `index.html` 即可打开，无需安装软件或上传数据到服务器。要公开发布，请阅读 [PUBLISH-TO-GITHUB-PAGES.md](PUBLISH-TO-GITHUB-PAGES.md)。

## 使用顺序

1. 在“盟员档案”新增成员，录入团组、职责、基础战力、到场次数与纪律信息。
2. 在“战报识别”上传截图，点击识别；核对系统提取的武勋、杀敌、拆迁等数据，确认后保存。
3. 在“赛季总览”查看综合贡献排行与需要跟进的成员。
4. 定期点击右上角“导出数据”备份。换电脑时用“导入数据”恢复。

## 注意

- 截图识别在浏览器内完成，但首次使用需要浏览器可访问中文 OCR 组件。
- 游戏战报的版式会随版本、场景变化；识别结果仅作录入辅助，保存前请人工核对。
- 网站将数据保存在当前浏览器的本地存储中；清理浏览器数据前请先导出备份。
